🧠 情绪识别算法（本地推理）

完全在浏览器端运行，基于 face-api.js 加载的 TensorFlow.js 预训练权重，三阶段级联：

阶段模型输入 → 输出
L1 人脸检测TinyFaceDetector（SSD + MobileNetV1 深度可分离卷积）RGB 张量 → 人脸框 + 5 关键点 + 置信度
L2 关键点对齐FaceLandmark68Net对齐后人脸 → 68 个关键点
L3 表情分类FaceExpressionNet（可分离卷积 + GAP + FC）对齐人脸 → 7 类 softmax 概率

7 类输出：neutral / happy / sad / angry / fearful / disgusted / surprised。权重全部放在项目 models/，断网可用。

情绪融合算法（自行实现，5 步）

  1. 多脸面积加权融合：p̄ = Σ(a_j·p_j)/Σa_j，aj 为人脸框面积，画面中占主要位置的人影响更大。
  2. EMA 时序平滑：p_t = α·p̂_t + (1−α)·p_{t−1}，α = 0.35，抑制单帧抖动，避免表情一闪就切歌。
  3. VA 二维映射：V = Σ p_i·v_i，A = Σ p_i·a_i，把 7 类离散概率投影到效价-唤醒连续空间。
  4. 可信度判定：需满足 p_max ≥ 0.45 且 p_max − p_second ≥ 0.12，否则输出「待确认」，不强行推荐。
  5. 情绪强度：intensity = p_max × (1 + 0.5|V|)，高唤醒的愤怒比中性的平静更强烈。

🎵 歌曲推荐算法

推荐 = 目标锚点构造 + 六项加权打分 + MMR 多样性重排。

Step 1 目标 VA 锚点

target = α · VA(当前情绪) + (1 − α) · VA(目标情绪)

策略α目标效果
共情0.85= 当前情绪悲伤时放悲伤的歌，被理解
调节0.20修正方向（如悲伤→温和明亮）轻轻把情绪带出来
反差0.00= 相反 VA用相反曲风打破情绪循环
混合0.55折中默认，七分共情三分调节

BPM* = 60 + (A + 1)/2 × 90

Step 2 六项加权打分

Score = 0.34·SimVA + 0.26·Matchtag + 0.14·SimBPM + 0.06·Quality + 0.10·Novelty − 0.26·MMR

  • SimVA = 1 − √((Δv)²+(Δa)²)/(2√2)
  • Matchtag = Jaccard(情绪期望标签, 歌曲标签)
  • SimBPM = exp(−(bpm−bpm*)²/(2σ²))，σ = 22
  • Quality：曲库质量 / 能量先验
  • Novelty = 1/(1+曝光次数×0.6)，避免总推同样几首
  • MMR = max cos(feat候选, feat已选)，6 维特征，惩罚同质化

Step 3 MMR 贪心重排

每轮选 argmax(Score − 0.26·maxSim)，既保证相关性又保证歌单有变化，不会八首歌都是一个味道。

曲库双通道

  • 本地：14 首原创器乐（audio/*.mp3），覆盖 7 种情绪各 2 首，可离线播放。
  • 在线：iTunes Search API（JSONP 免密钥），按情绪关键词实时检索并返回 30 秒试听直链。
